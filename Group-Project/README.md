# Group Project: TravelMate

**Live site:** https://travelmate-1-hezl.onrender.com

A responsive React travel web app built with Vite, React Router, reusable components and browser `localStorage`.

## Features
- Landing page with hero search, featured places and travel tips
- Registration and login with validation and a localStorage session
- Protected dashboard, planner and profile routes
- Favourite places: create, edit and delete
- Destination search (OpenStreetMap Nominatim) and filters
- OpenStreetMap embed with a Google Maps navigation link
- Trip planner, budget estimator and packing checklist
- Dark/light mode, toast messages and empty states
